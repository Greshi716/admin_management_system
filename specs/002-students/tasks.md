# Tasks: Students and Class Records (F1)

**Input**: Design documents from `/specs/002-students/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/openapi.yaml, quickstart.md

**Tests**: Included, written together with the code in the same task (constitution Principle VIII, FR-016). Backend tests carry `@Covers("FR-xxx")`; Playwright test titles start with the FR ids. One task covers one group of files, never one class.

**Organization**: Grouped by user story. Shared plumbing (schema, master data lookup, audit history, sensitive-column rule, entities) is in Phase 2. The shell restyle is exactly one task (T024).

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an incomplete task)
- **[Story]**: US1 to US4, mapping to the user stories in spec.md
- Commit after every task, with the FR ids in the message (CLAUDE.md). Never commit to `main`.

## Path Conventions

- `BE/` = `management/src/main/java/com/admin/management/`; `BT/` = `management/src/test/java/com/admin/management/`
- Migrations: `management/src/main/resources/db/migration/`
- `FE/` = `frontend/src/app/`; e2e specs in `frontend/e2e/`
- Follow the nearest F0 example for each kind of file (for example `BT/masterdata/StandardIT.java`, `FE/features/masterdata/standards/`)
- Synthetic data only (constitution VI): no real names, Aadhaar numbers or phone numbers anywhere
- Needed on the machine before the first task: JDK 21 (`JAVA_HOME`), PostgreSQL with the databases `admin_management_db` and `admin_management_test`, Node as in F0, and port 8080 free for the Playwright run
- Controller files (kept apart so tasks do not edit the same file): `BE/students/StudentController.java` (register, edit, left, enrollments, pick-lists, name-matches, `/edit`), `StudentListController.java` (search, export), `StudentProfileController.java` (profile, history), `StudentPhotoController.java` (photo)
